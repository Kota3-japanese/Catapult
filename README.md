
# Be Smile

## 概要

Be Smile は、写真から笑顔スコアを計測し、そのときの写真やコメントを記録できるWebアプリです。

日々の笑顔を写真と一緒に残し、カレンダーから過去の記録を振り返ることができます。何気ない日常の中で、自分の表情や気持ちの変化を見つめ直すことを目指しています。

## 主な機能

### 1. 写真撮影・笑顔スコアの計測
- カメラを起動して写真を撮影する
- 撮影した写真を解析して笑顔スコアを計測する
- 計測したスコアを確認する

### 2. 笑顔の記録
- 撮影した写真を保存する
- 笑顔スコアを保存する
- 日付とコメントを一緒に記録する
- 保存した記録をあとから確認する

### 3. カレンダーで振り返る
- カレンダーから過去の記録を確認する
- 日付ごとに写真やコメントを振り返る
- 記録の詳細を表示する

### 4. 記録の管理
- 保存した記録を削除する
- 写真をまとめてダウンロードするアルバム機能を目指す

## 使用技術

- HTML

- MediaPipe Tasks Vision
- Supabase

  - Storage：写真の保存
  - Authentication：ユーザー認証

## 使い方

1. Be Smile を開く
2. カメラを起動する
3. 写真を撮影する
4. 撮影した写真から笑顔スコアを計測する
5. コメントを入力する
6. 写真・スコア・コメントを保存する
7. カレンダーから過去の記録を振り返る

## データの保存

記録データはSupabaseのデータベースに保存し、写真はSupabase Storageに保存する構成です。

記録には、主に次の情報を使用します。

- 日付
- 写真の保存先
- 笑顔スコア
- コメント

## 開発方針

Be Smile は、自分で撮影した写真から笑顔スコアを計測し、その瞬間を記録として残すアプリです。

リアルタイムでの笑顔スコアの自動計測、目標スコアに応じた自動撮影、アラーム・音声機能は実装対象に含めません。

写真撮影、笑顔スコアの計測、記録の保存、カレンダーでの振り返りといった基本機能を整え、使いやすいアプリを目指します。

## 公開・利用環境

GitHub Pagesでの公開を想定しています。

カメラ機能を利用するには、HTTPSなどの安全な接続環境と、ブラウザからのカメラ利用許可が必要です。

Supabaseを利用する機能については、認証・データベース・Storageの設定が必要です。
