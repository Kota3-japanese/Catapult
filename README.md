# ご機嫌メーター（仮） --- フロントエンド

怒った顔から笑顔になれた瞬間を写真と一言で記録し、カレンダーから振り返るWebアプリのフロントエンドです。

## 目的

-   笑顔の記録を日付ごとに整理する
-   写真と短いメモをカレンダーから振り返る
-   カメラ画面と記録画面をわかりやすくする

## 使用技術

-   HTML
-   CSS
-   JavaScript（Vanilla JS）
-   カメラ表示：ブラウザの `getUserMedia()` API
 
 **現在の実装状況:** フロントエンドの試作段階です。MediaPipe Face
 Landmarkerによる笑顔スコア計測・3秒間の条件判定・自動撮影、およびSupabase/Firebaseとの連携は、別途実装・接続が必要です。現時点の記録保存はブラウザの
`localStorage` を使用する試作構成です。

## 主な画面・機能

-   月別カレンダー
-   日付ごとの写真サムネイル表示
-   記録の詳細表示
-   カメラ画面
-   写真とメモの保存（試作版）
-   記録の削除
-   PC・スマートフォン向けのレスポンシブレイアウト

``` text
smile-memory-frontend/
```

## 今後の実装予定

-   MediaPipe Face Landmarkerの導入
-   顔の特徴から笑顔スコアを算出するロジック
-   設定したスコアを3秒間維持した場合の自動撮影
-   写真ストレージと記録データベース（SupabaseまたはFirebase）の接続
-   エラー表示、アクセシビリティ、ブラウザごとの動作確認
